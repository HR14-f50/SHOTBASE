# SHOTBASE 管理UI更新仕様（2026-09-19）

## ログアウト・公開設定

ログアウトリンクは専用の確認ページを開きます。「ログアウトする」を押したときにだけログアウトします。「キャンセル」でマイページに戻れます。URLを開くだけではログアウトせず、送信時にはCSRFを検証します。

これから追加する写真はデフォルトで「公開」です。既存写真の公開状態は変更していません。写真が公開でも、所属プロジェクトが下書き・非公開であれば、外部の閲覧者には表示しません。

## マイページ

上部にあった本人専用のプロジェクト管理エリアを削除し、下部のプロジェクト一覧へ統合しました。

- 一覧先頭に、既存カードと同じ構成の「新しいプロジェクトを作成」カードを配置。
- サムネイル領域は同じサイズの正方形にそろえ、新規作成カードには＋を表示。
- 本人には公開・非公開・下書きの全プロジェクトを表示。並び替え・年月・タグの絞り込みも利用可能。
- 本人がカードを開くと、そのプロジェクトの編集・写真管理画面へ移動。
- 本人以外には公開済みのプロジェクトだけを表示し、管理ボタンは表示しない。

## プロジェクト詳細

青系のカードとボタンで全体の雰囲気を統一し、タイトルを少し小さくしました。撮影日・公開状態・写真枚数をまとめ、編集と写真一覧に進めます。

「ログアウト時の表示をプレビュー」は別タブで開きます。ログイン状態を維持したまま、公開ページの実際の公開条件と、未ログイン用ナビゲーションで表示します。下書き・非公開のプロジェクトは「見つかりません」と表示されます。プレビューを理由に非公開の内容を公開する処理はありません。

## 写真一覧・詳細

写真一覧の先頭に「写真を追加」と＋を表示したカードを配置しました。写真枠は正方形ですが、画像自体は縦横比を保って枠内に収めます。縦写真・横写真とも切り抜きません。

写真詳細では画面上のタイトル見出しを削除し、写真を中央に大きく表示します。下にはキャプション・タグ・公開状態を配置します。「前の写真」「次の写真」は同一プロジェクト内だけを移動し、一覧と同じ新しい順（同時刻の場合はID順）で並びます。先頭・末尾では移動できない方向を無効にします。

## 写真登録・編集

写真登録と写真編集のタグ欄に「新しいタグを追加」を設置しました。作成したタグは自動で選択されます。同名の利用可能なタグがあれば再利用します。タグ名は100文字以内で、他の会員専用タグは指定できません。入力欄にタグ名が残っている状態で写真を登録・編集完了した場合も、タグを作成して付与します。

写真編集は他のページと同じカード構成に変更しました。

- ウォーターマーク位置は9分割のラジオボタン。
- 「ユーザー設定を使う」を選ぶとプロフィールの位置指定に追従。
- 「編集完了」で保存し、編集を始めた写真一覧・プロジェクト詳細・写真詳細へ戻る。
- 「元に戻す」は未保存の入力を破棄し、最後に保存した写真情報を読み直す。
- 戻り先はサイト内の決められた3種類に限定。

「タグを追加」で作成したタグ自体はその時点で保存されるため、「元に戻す」を押しても利用可能なタグとして残ります。写真への関連付けは「編集完了」で確定します。

## ウォーターマークの見本

プロフィール編集の9分割位置選択の右側に、球場の見本画像を配置しました。スマホなど幅が狭い画面では下側に並びます。

内容、サイズ、色、不透明度、位置、オン／オフを変更すると、保存前の設定で見本が更新されます。実際の写真加工と同じ描画処理を使います。見本を見るだけではプロフィールや既存写真は更新されません。「プロフィールを保存」で確定します。

## 移行と確認

MAMPには `migrations/20260919_public_photos.sql` を適用済みです。このSQLは新規写真の初期値のみを公開へ変更します。別環境では以前のマイグレーションの後に適用してください。

テスト会員で以下を確認しました。

- 確認前・不正送信ではログアウトしないこと、確認後のログアウト。
- 本人だけに下書きが見えること、並び替え・年月指定。
- 公開プロジェクトのゲストプレビューと非公開プロジェクトの非表示。
- 新規アップロードの公開初期値、登録画面・写真編集からのタグ作成と付与。
- 写真詳細の同一プロジェクト内ナビゲーション、編集後の3種類の戻り先。
- ウォーターマーク見本の更新、未認証アクセス・不正送信の拒否。
- タグUIの追加・選択・重複防止、削除確認のキャンセル。
- ブラウザーでの見本表示、写真一覧・写真詳細のスマホ幅390px表示。

検証用の会員・写真・タグは削除済みです。既存のデモ会員の4プロジェクト・24枚は維持しています。
