# SHOTBASE：タグ・ウォーターマーク・ギャラリー調整ガイド

更新日：2026年9月19日

以下のファイル名は `/Applications/MAMP/htdocs/shotbase/` を起点としています。VS Codeでshotbaseフォルダを開いて編集してください。

## 反映した内容

- 写真のタイトル入力と表示を廃止し、稼働中DBの `photos.title` カラムを削除しました。プロジェクト名は引き続き利用できます。
- 写真編集の9分割位置選択には、写真の個別設定、またはプロフィールの既定位置を初期表示します。「プロフィールの位置設定に合わせる」を選ぶと、以後もプロフィール設定に追従します。位置を個別に選ぶと追従が外れます。
- 写真編集では実際の元画像にウォーターマークを描いたプレビューを表示します。プロフィール編集では設定用サンプルを表示します。プレビューだけでは保存されません。ウォーターマークがオフの会員は元画像と「オフ」の案内を表示します。
- タグは表示用・選択用を共通デザインに統一しました。選択済みは濃い色です。チェックボックスは見た目だけを隠し、キーボード操作は維持しています。
- 人気タグは件数をタグ内に表示し、左詰め・折り返しなしにしました。長い場合は横スクロールできます。
- `admin/photo.php` にカバー指定・自動選択へ戻すボタンを追加しました。非公開の写真をカバーにしても、訪問者には別の公開写真を使用します。カバー写真を削除すると自動選択へ戻ります。
- ピックアップを1行の横スクロールギャラリーに変更しました。左右のボタンやスマートフォンのスワイプで移動できます。
- 自分のプロフィールに訪問者プレビューボタンを追加しました。ログインを維持したまま管理操作と非公開データを隠し、絞り込み先や写真・プロジェクトへのリンクもプレビューを引き継ぎます。
- プロフィール上部の余白、アイコン、ギャラリー、プロジェクト行をコンパクトにしました。デモ・画面1280×800では、プレビュー案内がある状態でも2件目の約半分が見えることを確認しました。文章量や画面サイズによって見える範囲は変わります。

## タグの色を変更する場所

`includes/tag_palette.php` の5行目から始まる `tagPalette()` が、種類別の配色設定です。現在は全種類を青系にそろえています。

| 種類のキー | 対象 |
| --- | --- |
| team | チーム |
| player | 選手 |
| stadium | 球場 |
| event | イベント |
| custom | 独自タグ |
| other | その他・不明な種類 |

例えば `'team' => $blue,` を次に置き換えると、チームタグだけ配色を変えられます。色は6桁のカラーコードで指定します。

```php
    'team' => [
      'bg' => '#eef3f8',
      'fg' => '#355d83',
      'border' => '#c5d3e1',
      'selected' => '#355d83',
      'selected_text' => '#ffffff',
    ],
```

`bg` は通常背景、`fg` は通常文字、`border` は枠、`selected` は選択時背景、`selected_text` は選択時文字です。全種類をまとめて変更する場合は7行目の `$blue` を変更します。従来のDB内のタグ個別色より、この種類別設定を優先します。

形・角丸・余白・文字サイズは `assets/css/tags.css` を編集します。`.tag` などが共通チップ、`:has(input:checked)` を含むセレクターが選択状態、`.tagUseCount` が件数、`.popularTagList` が人気タグの並び方です。

## ウォーターマークの文字サイズと太さ

写真に焼き込む文字はPHPで描画します。CSSの `font-size` や `font-weight` では変更できません。共通設定は `includes/watermark_style.php` にまとめました。

| 場所 | 設定 | 変更方法 |
| --- | --- | --- |
| 8行目 | `size_factors` | `small`・`medium`・`large` の数値を増やすと大きくなります。画像の短辺に対する倍率です。 |
| 9行目 | `font_weight` | `400` は標準、`700` は太字です。対応する日本語フォントを同梱しています。 |
| 14行目 | `line_height` | 1行目とサイト名の行間を調整します。 |
| 15行目 | `padding_factor` | 画像の端から文字までの余白を調整します。 |

例：中サイズを少し大きくして太字にする場合は、`medium` を `0.038`、`font_weight` を `700` に変更します。長い文字が画像からはみ出す場合は自動で縮小されます。

実際の処理は `includes/watermark.php` の `drawWatermark()`（31行目）です。37〜38行目で文字サイズを計算し、57行目の `imagettftext()` で描画します。フォントは `watermarkFont()` で選択します。環境変数 `SHOTBASE_WATERMARK_FONT` を設定している場合は、その指定が優先されます。

`assets/css/admin.css` の `.watermarkLivePreview`（216行目付近）と `.watermarkLivePreview img` は、プレビュー枠や画像の表示サイズを調整する場所です。写真内の文字の大きさ・太さとは別です。

設定ファイルの変更は、新しいアップロードとプレビューに反映されます。既存の保存画像を更新するには、その写真を編集して「編集完了」を押してください。プロフィールのウォーターマーク設定を変更して保存した場合も再生成されます。設定ファイルだけの変更では、保存済み画像は自動で書き換わりません。

## レイアウトを調整する場所

`assets/css/gallery.css` に今回の調整をまとめています。

- `.profileIdentityWrap`：プロフィール情報の上下余白
- `.pickupGallery`：ギャラリーの高さ、1行表示、横スクロール
- `.profileProjectRow`：プロジェクト行の余白
- `.projectCoverLink`：プロジェクトカバーの大きさ
- モバイル用メディアクエリー：スマートフォン向け表示

左右ボタンの動作は `assets/js/profile-gallery.js`、ウォーターマークの更新は `assets/js/watermark-preview.js`、画像生成は `admin/watermark_preview.php` です。

## DBと確認結果

DB変更は `migrations/20260919_gallery.sql` に保存し、このMacの稼働中DBには適用済みです。既存DBを使い続ける場合、再実行は不要です。過去のSQLダンプは当時の状態を残しています。別環境へ移す場合は、その環境の移行状況を確認して適用してください。作業前にDBとコードのバックアップを保存しました。

写真タイトル廃止、位置継承と個別指定、プレビュー、カバー指定、非公開カバーの代替表示、所有者以外の変更拒否、訪問者プレビュー、カバー削除時の解除を動作確認しました。検証用に作成したアカウントとデータは削除済みです。スマートフォン幅390pxでページ全体の横はみ出しがないことも確認しています。
