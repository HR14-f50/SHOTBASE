# SHOTBASE プロフィール管理仕様

> 2026-09-19更新：プロジェクト管理は下部の既存一覧に統合しました。最新の導線と見本表示は `admin-ui.md` を参照してください。

## 今回の変更

メール認証は見送りとし、登録後すぐに利用できる方式を継続します。

独立した管理画面は廃止しました。投稿会員はログイン後、自分のプロフィールへ移動します。プロフィール内の本人専用エリアからプロジェクトの作成、非公開を含むプロジェクトの編集、写真の追加・管理へ進めます。旧 `admin/index.php` は古いリンクへの対応として転送処理だけを残しています。

閲覧限定会員はアカウント画面を使用し、公開プロフィールや投稿機能は持ちません。

## カスタムアイコン

白線画の素材と背景色を組み合わせ、選択と同時にプレビューを表示します。新規登録の閲覧会員用ステップ3と、両会員種別のプロフィール編集で共通の仕組みを利用します。

列挙されたモチーフは、野球・応援など13種と動物14種の合計27種でした。「19種」という見出しより、具体的な列挙内容を優先して全27種を実装しています。

- 野球ボール、バット、グラブ、帽子、ヘルメット、キャッチャーマスク、スパイク、応援メガホン、ツインスティック、四角形のフラッグ、傘、星、ハート。
- 兎、虎、ハムスター、燕、コアラ、龍、鯉、鷹、ライオン、狐、リス、水牛、鴎、犬鷲。
- 背景12色：赤、オレンジ、黄色、緑、水色、青、紺色、黒、えんじ色、ピンク、紫、濃いグレー。

素材は拡大しても輪郭が崩れにくいSVGのオリジナル線画です。球団の公式マークは使用していません。素材一覧・色は `includes/icon_catalog.php`、線画は `assets/icons/motifs/`、合成画像は `avatar.php` で管理します。URLに指定できる素材と色を限定しているため、任意のファイルは読み込めません。

## プロフィール編集

| 設定 | 閲覧限定会員 | 写真投稿会員 |
| --- | --- | --- |
| 素材と背景色によるアイコン | 対応 | 対応 |
| アイコン画像のアップロード | なし | JPEG／PNG／WebP、5MB未満 |
| 投稿済み写真からアイコン選択 | なし | 自分のプロジェクト内の写真のみ |
| ニックネーム | 20文字以内 | 20文字以内 |
| 自己紹介 | なし | 200文字以内 |
| プロフィールタグ | 合計10個まで | 合計10個まで |
| プロフィールのテーマカラー | なし | ホワイト・プロ野球12球団・パープル・ピンク・ダークモードの16種類 |
| ウォーターマーク設定 | なし | 対応 |

閲覧会員のタグは本人のアカウント画面に表示します。「写真投稿会員に変更する」で公開プロフィールが作成されることを説明してから変更できます。

画像アイコンは中央を正方形に切り抜き、256pxで保存します。投稿写真を選んだ場合もアイコン用に複製するため、元の写真を編集したり削除したりしてもアイコンは失われません。

ユーザー名は登録後に変更できません。登録画面にもその旨を表示し、編集時はサーバー側でもユーザー名を更新しません。

「プロフィールを保存」で変更を反映します。「やり直す（元に戻す）」は未保存の入力を破棄し、最後に保存した内容を読み直します。

## ピックアップとプロジェクト管理

ピックアップ写真の選択は編集画面から移動しました。自分のプロフィールの「ピックアップ写真を変更」を開き、公開プロジェクト内の公開写真を最大12枚選びます。別ユーザーの写真は指定できません。

「自分のプロジェクト」エリアは本人にだけ表示します。ここから新しいプロジェクトを作成し、一覧を開いて既存プロジェクトを編集できます。非公開タイトルは外部の閲覧者には表示しません。

## ウォーターマーク

- 1行目：ユーザー名（@付き）／ニックネーム／自由入力20文字以内。
- 2行目：SHOTBASEを固定で表示。
- 文字サイズ：大・中・小。写真のサイズに合わせて調整し、長い文字列は写真内に収まるよう縮小。
- 文字色：黒・白。
- 不透明度：100%・50%・20%・10%。
- 位置：3×3のラジオボタンから選択。

設定を変更して保存すると、自分の既存写真を元画像から再生成します。文字を重ね続けることはありません。表示画像は従来どおり2MB以内です。写真別に位置を指定している場合はその指定を優先します。各写真の編集画面で「ユーザー設定を使う」に戻すと一括設定が適用されます。オフにして保存すると既存写真のウォーターマークも取り除きます。新規アップロードにも最新の設定を使います。

再生成は保存処理中に行うため、写真が多い場合は時間がかかります。元画像が失われている場合はエラーとして保存を中止します。画像は別ファイルへ作成し、保存が成功してから古い表示画像を削除します。

日本語表示には同梱のNoto Sans CJK JPを利用します。フォントとライセンスは `assets/fonts/` に保存しています。配布元は [Noto CJK公式リポジトリ](https://github.com/notofonts/noto-cjk/tree/main/Sans) です。別のフォントを使う場合は環境変数 `SHOTBASE_WATERMARK_FONT` に対応フォントの絶対パスを設定できます。

## 退会

プロフィール編集の「退会」から確認画面へ進みます。以下をそろえた場合のみ削除します。

1. 「退会すると登録した写真やプロジェクトも全て削除されます」という説明を確認。
2. パスワードで本人確認。
3. 削除確認のチェックと、最後の確認ダイアログ。

アカウント・プロジェクト・写真・関連タグやいいねを削除し、写真の原本・表示画像・専用アイコンも削除します。共通素材や他会員が参照するファイルは残します。失敗時にはデータと一時退避した写真を元に戻し、成功時にはログアウトします。
