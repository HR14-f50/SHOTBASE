# SHOTBASE：プロジェクト管理・タグ検索・テーマ更新

2026年9月20日

## ヘッダー・プロフィール

ヘッダーは通常レイアウトの `sticky` として表示します。下へスクロールすると退避し、上へスクロールすると再表示します。CSSの `position: fixed` は使用しません。キーボードでヘッダー内を操作している間は隠しません。

自己紹介は横幅に合わせて折り返します。本文中の改行をスペースへ置き換える処理は維持しています。

## 複数タグ検索

プロフィール・公開プロジェクト・管理プロジェクト・タグ検索ページで、タグを選ぶとその場でURLを更新して絞り込みます。送信ボタンはありません。「選んだタグをすべて含む写真」を探すAND検索で、プロフィールではその写真を含むプロジェクトを表示します。プロフィールの年月絞り込み・並び順とも併用できます。

公開画面の検索・件数には非公開写真を含めません。管理プロジェクトでは、自分の非公開写真も対象です。

プロフィールの人気タグは開閉式です。PCでは一覧に最大高さを設け、タグが多い場合は領域内をスクロールできます。スマートフォンでは「撮影月から探す」と同じ開閉操作を使います。プロジェクト一覧は1ページ20件で、複数ページになると前後ページを表示します。

タグを付与する画面の「タグを選ぶ」は、チームごとのカード、リーグ・大会、球場、ユーザーが追加したタグ、その他のタグに分けています。チームカード内では、チームタグと選手の守備位置カテゴリをまとめて表示します。検索時はチームを選択していなくても一致する選手を表示します。

プロジェクト画面のスマートフォン表示では自己紹介・プロジェクト数・写真数を省略します。プロフィール導線は独立ボタンではなく、サイドバーのアイコンをクリックして開きます。プロフィールのピックアップギャラリーでは、スマートフォン時だけ左右ボタンを画像の下へ移動します。

## プロジェクト管理を1ページへ統合

`admin/photos.php` は削除しました。写真追加・写真詳細・写真編集への導線は `admin/project.php?id=...` に統一しています。古いURLのブックマークは新しいプロジェクトURLへ変更してください。

公開・管理プロジェクトの左側には「このプロジェクトのタグ」を表示し、以前の「よく投稿するタグ」と置き換えました。プロジェクトタイトルを小さくし、両画面を同様の構成にしました。

### タグを一括追加する手順

1. 管理プロジェクトで「写真にタグを一括追加」を開きます。
2. 追加するタグを選びます。
3. 対象写真を選びます。「表示中の写真をすべて選択」も使えます。
4. 「選択した写真にタグを追加」を押します。

既存タグを残して追加し、重複は増やしません。各写真の合計は最大10件です。1枚でも上限を超える場合、または別のプロジェクトの写真が含まれる場合は、全件の保存を中止します。

### 更新日時

公開・管理プロジェクトに日時、プロフィールのプロジェクト一覧に日付を表示します。プロジェクト情報・カバーの変更、写真の追加・編集・削除、タグ一括追加、保存画像のウォーターマーク再生成で更新します。画面を開くだけでは更新しません。

## 写真のタグ制限と削除

- 1枚につき最大10件、タグ名は最大12文字です。写真編集・アップロード・一括追加の保存処理でも検証します。
- 既存タグには削除ボタンを表示しません。写真から関連付けを外したい場合は、タグの選択を解除して保存します。タグ自体は残ります。
- 今回の写真編集画面で新しく作った未使用タグにだけ「×」を表示します。確認後に削除します。
- 同じ名前の既存タグを再利用した場合は削除対象になりません。
- タグを写真などに保存すると削除できなくなります。ページを開き直した場合や編集開始から2時間を過ぎた場合も、前の編集で作ったタグは削除できません。
- 以前の12文字を超えるタグは勝手に改名・削除しませんが、新しい保存で付与することはできません。

## 写真ごとのウォーターマーク

写真編集で「文字サイズ（小・中・大）」と「文字の濃さ（100%・50%・20%・10%）」を選べます。位置とあわせて保存前のプレビューへ反映します。

「プロフィール設定に合わせる」で個別指定を解除します。個別指定した写真は、後からプロフィールのウォーターマーク設定を変更しても、そのサイズ・濃さを優先します。ウォーターマークがオフの場合、設定は保存できますが文字は表示しません。

## テーマカラー

プロフィール編集の丸い色見本を選ぶと、その場で表示を変更し、自動保存します。他の入力欄はその操作では保存しません。保存に失敗した場合は元の色へ戻して案内します。連続で選んだ場合は最後に選んだ色が残るよう順番に保存します。選択肢はホワイト、プロ野球12球団、パープル、ピンクの15種類です。

適用先は本人のプロフィール、公開・管理プロジェクト、公開・管理写真詳細、写真編集、プロフィール編集などです。訪問者が閲覧してもページ所有者のテーマを使用します。タグの種類別配色は既存の共通設定を維持します。

テーマは即時保存のため、「やり直す」で以前の色には戻りません。戻したい場合は元の色を選んでください。
