# SHOTBASE：サイドバー・タグ・アイコン更新

2026年9月19日

## 画面の変更

- プロフィール情報を左の `.profileAreaB` 内へ移動しました。スマートフォン幅では上にまとめます。
- 公開プロジェクトページと公開写真詳細ページにも同じプロフィール・人気タグを表示します。この2ページには撮影年月アーカイブを表示しません。
- 自己紹介の改行は表示時にスペースへ変換します。本文を削らず1行で表示し、長い場合は横スクロールできます。保存済みの自己紹介本文はそのまま残します。
- 共通ヘッダーは高さ約38pxに縮小しました。固定・追従表示は行わず、ページ最上部の14pxの領域にカーソルを置くと表示します。キーボードでヘッダー内に移動したときも表示します。タッチ端末では常時表示します。
- ピックアップの高さをPCで132pxから198px、スマートフォン幅で100pxから150pxに変更しました。
- ギャラリーの矢印は画像の左右端に重ね、ホバー・キーボードフォーカスで表示します。タッチ端末では常時表示します。
- 写真詳細はメイン領域いっぱいに写真を配置し、縦横比を維持して全体が見えるようにしました。

## タグの操作

写真編集の「新しいタグを追加」に `ナイター、遠征,外野席` のように入力すると、3つのタグを作成して選択します。一度に20個まで、1タグ100文字以内です。重複した名前は再利用します。追加ボタンを押さず「編集完了」で保存しても、区切りを処理します。

- チップの選択を外す：今回の写真からタグを外します。「編集完了」で確定します。
- 自分のタグの右の「×」：確認後、その登録タグ自体を即時削除します。すべての写真・プロジェクト初期設定から関連付けが解除されます。写真やプロジェクト本体は消えません。「元に戻す」では取り消せません。
- 共通タグと他の会員が作ったタグは削除できません。サーバー側でもログイン・所有権・送信元確認用トークンを検証します。

同じ追加UIを使う写真アップロード画面でも、区切り入力が利用できます。

## アイコンの操作

「素材と色で作る」に「無地（白線画なし）」を追加しました。背景色だけのアイコンを作れます。共通部品を使う新規登録画面にも反映されます。

写真投稿会員は「画像をアップロード」を選び、JPEG・PNG・WebPの5MB未満の画像を指定します。プレビューを見ながら「横の位置」「縦の位置」を調整し、プロフィールを保存してください。選択範囲を256×256pxで切り抜きます。正方形の画像では位置を変えても表示は変わりません。

保存後に再調整したい場合は、元の画像をもう一度選択します。「投稿した写真から選ぶ」は画面・受付処理ともに削除しました。すでに設定済みのアイコンは「現在のアイコン」で維持できます。
